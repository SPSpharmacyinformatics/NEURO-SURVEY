# Third-party assets (vendored locally — zero remote requests)

These files are served from this site's own `/static/` so that the page makes
no third-party network calls. Licenses permit redistribution.

- `js/chart.umd.min.js` — **Chart.js v4.4.3** · MIT License · https://www.chartjs.org/
  Copyright (c) Chart.js Contributors.
- `js/qrcode.min.js` — **qrcode-generator v1.4.4** · MIT License · https://github.com/kazuhikoarase/qrcode-generator
  Copyright (c) 2009 Kazuhiko Arase.
- `fonts/Baloo2-*.woff2`, `fonts/fonts.css` — **Baloo 2** · SIL Open Font License 1.1 · https://fonts.google.com/specimen/Baloo+2
  The typeface is loaded as a variable font (one file per Unicode subset:
  latin, latin-ext, devanagari, vietnamese) covering weights 400–800.
